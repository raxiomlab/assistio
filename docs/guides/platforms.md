# Desktop, Web & Android

AssistIO runs the **same engine** everywhere. Your conversations, memory and work
stay in sync across every device you connect — no manual export, no copy-paste
between machines.

## Desktop

The full experience. Run everything locally on your own machine, with native
windows and the ability to run **multiple instances** side by side (for example,
one workspace per project).

- Best for: development, heavy file work, long background tasks.

## Web

Open your workspace in any browser. Same conversations, same boards, same memory —
nothing to install.

- Best for: quick access from any machine, checking on work in progress.

## Android

Install the app and **pair it with your desktop by QR code**. Your phone then mirrors
the same session in real time, and doubles as a remote companion for the desktop app.

- Best for: monitoring running tasks, approving actions, and chatting on the go.

## One session, many views

All surfaces mirror the same live session in real time. There is no refresh step and
no risk of two copies drifting apart: there is one writer and many views. If a task is
running on your desktop, you can watch it, pause it or approve a pending action from
your phone — and it reflects instantly everywhere.

## Which should you use?

Start on **desktop** for the full power, add **web** when you want zero-install
access, and pair **Android** so your work follows you. The data model is identical
across all three.
