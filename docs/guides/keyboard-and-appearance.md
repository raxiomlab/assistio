# Keyboard & appearance

AssistIO is built to be fast from the keyboard and comfortable to look at, and you can
make it yours.

## Command palette

Everything important is reachable from the **command palette** — open it and start
typing to jump to a conversation, run a task, change a setting or trigger an action.
It is the fastest way to move once you have a few workspaces going.

## Keyboard shortcuts

Common actions have shortcuts so you rarely need the mouse. The shortcuts are listed in
the in-app help; the important ones to learn first are opening the palette, creating a
new conversation, and sending/queueing a message.

## Themes and light/dark

AssistIO ships **light and dark themes** and respects your system preference. You can
switch at any time from the appearance settings.

## Appearance system

The appearance system is comprehensive: themes, VS Code-style theme support, type scale
and layout density. If you like a **dense, compact UI**, you can dial the density in so
lists and panels use the space tightly rather than padding everything out.

## Custom agents' personalities

Appearance is not only visual. A **custom agent** can carry its own personality and
instructions, so the assistant's voice is part of "making it yours" too. See
[Tools, MCP & plugins](tools-and-plugins.md).

> Tip: the whole appearance system is local — changing it does not touch your data or
> your provider configuration.
