# Features overview

Everything below ships in the same local-first core — no add-ons, no features gated
behind a paid plan. This page is a map of what AssistIO can do; the linked pages go
deeper.

## Talk and iterate

- Real-time streaming answers, token by token, that never freeze while thinking.
- Edit, regenerate, branch (fork) and rewind any message.
- Queue messages while the agent is still working, instead of interrupting it.
- Automatic conversation titles so your history stays readable.
- Crash-safe recovery: if the app closes mid-answer, it resumes where it left off.

## Work with your files

- Read, write, move, rename and delete files and folders.
- Targeted edits with a **visual diff** (`+12 −3`) before anything changes.
- Built-in file browser and code editor.
- **Staleness guard**: the agent re-reads a file right before editing it, so it never
  overwrites changes it hasn't seen.
- Attach files to any message — text files go into context, images are understood
  visually.

## Run real work in the background

- Create tasks with objectives, steps, checkpoints and stop conditions.
- Run them in the background, then pause, resume or cancel.
- Agents can delegate to specialized sub-agents and coordinate with each other.
- See [Tasks & Kanban](tasks-and-kanban.md).

## Manage projects

- Kanban boards with custom columns, priorities, labels and due dates.
- Assign a card to an agent and it executes the work, then reports back on the card.
- GitHub integration: sync issues and pull requests, or let CI report back to a card.

## Build your own tools

- Connect external **MCP servers** to give agents new capabilities.
- Create custom plugins at runtime, no coding required.
- Import your setup from other tools (agents, prompts and conversations).
- See [Tools, MCP & plugins](tools-and-plugins.md).

## Remember and understand

- Persistent memory: semantic, episodic and procedural facts, scoped per conversation,
  per user or global.
- A knowledge graph built automatically from your conversations.
- Attach local folders as a knowledge base, kept up to date automatically.
- See [Memory & knowledge](memory.md).

## Stay in control

- Tool approval: you decide which actions run.
- Tool governance: disable any tool, with a full audit trail.
- Privacy by default: sensitive data is redacted before it leaves your machine.
- Secret vault for credentials.
- See [Tool approvals](tool-approvals.md) and [Privacy & security](privacy-and-security.md).

## Make it yours

- Multiple AI providers and models, including local CLI providers.
- Custom agents with their own personality, instructions and tool permissions.
- Voice input and narration.
- Command palette, keyboard shortcuts, themes and a full appearance system.
- See [Keyboard & appearance](keyboard-and-appearance.md).
