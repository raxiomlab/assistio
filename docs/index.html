FAQ

Questions, answered

Do I have to pay anything?
No. Use is free with no license limit. You only need an account with the AI provider you choose, which bills for model usage.
Does it work offline?
Yes for everything local: files, shell, memory, boards and history. Anything model-driven needs a provider connection - or run a local CLI provider on your own hardware.
Can I use it at my company?
Yes, for internal use, at no extra cost. Resale, redistribution and embedding it in another offering require written permission.
Where does my data go?
Only when you send something to an AI provider - and before that, sensitive data is masked automatically. Everything else stays local.
Could the agent run something dangerous?
It can, but never alone: every sensitive action asks for approval, destructive actions are blocked while other work is running, and you can disable any tool for good.
Does it work on my phone?
Yes. The Android app syncs with your desktop by QR code and follows conversations, tasks and boards live. The phone drives the view; execution stays where the server runs.
Who is IO, the little guy floating around?
IO is the mascot of this page: it follows your scroll, flies over the cards, sleeps when you leave it alone and plays with you. Drag it, throw it, double-click it - and open the arcade with the gamepad button in the corner. Rumor has it there is a secret code hidden somewhere.
